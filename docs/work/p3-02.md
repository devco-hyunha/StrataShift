# Goal p3-02: safetensors float expert → GGUF Q2_0 writer → 엔진 acceptance

- Phase: 3 (PolyStrata 연동·피드백)
- Branch: `feat/p3-02-safetensors-gguf`
- Status: in_progress (2026-10-16)

## 한 줄 목표

float32 expert 텐서를 담은 safetensors 입력을 Expert 단위 스트리밍으로 Q2_0 양자화해 엔진 GGUF v3
파일로 쓰고, 엔진 CPU 체인(strata-gguf --check 가드 PASS, strata-dequant PASS, strata_pack build+verify PASS)
을 그 GGUF에 대해 통과시킨다 — "임의 MoE safetensors → 엔진 pack" 파이프라인의 CPU 게이트.

## 근거

- Q2_0 contract: `docs/rea/bitpack_rules.md §1` — d=amax(fp16), code=clip(rint(w/d)+1,0,3),
  4 codes/byte LSB-first. 엔진 정본 `tools/gguf_writer.py quantize_q2_0` (pin c566ff4)과
  우리 `quant/pack.py q2_0_encode_row`가 **동일 바이트**여야 한다 (교차 테스트).
- GGUF v3 헤더/tensor 레코드 순서: `struct_layouts.md §1` VERIFIED (p3-01).
- 아키텍처 가드 compiled 키: `struct_layouts.md §1` VERIFIED — 가드 키 집합은 **preset 입력**
  (발명 금지). 기본 preset은 fixture의 compiled geometry (p3-01 Result의 키 표).
- 엔진 도구 read-only: `tools/gguf_writer.py` import (엔진 수정 없음, p3-01 하네스 관례).

## In

1. `quant/pack.py`: `quantize_q2_0_stream(values)` — float32 1-D (64의 배수) → 18 B 블록 스트림
   (엔진 quantize_q2_0와 바이트 동일, 교차 테스트로 확정).
2. `stream/mmap_reader.py` 확장: float32 tensor payload 제너레이터 (mmap, 단일 슬라이스).
3. `cli/main.py` GGUF convert 확장: safetensors 입력에 `--emit-gguf OUT` (Expert float 텐서
   `blk.{L}.ffn_{gate,up,down}_exps.weight`, shape (in,out,NE) GGUF 순) → 엔진 gguf_writer로
   Q2_0 tensor + 가드 preset 키 기록 → `.gguf` 산출. 가드 키는 preset JSON/기본 fixture 값.
4. 엔진 체인 acceptance: 산출 GGUF에 대해 strata-gguf --check PASS + strata-dequant PASS
   (0 violations) + strata_pack build/verify PASS — 하네스 `scripts/p3_engine_smoke2.py`.
5. 테스트: `tests/test_safetensors_gguf.py` — quantize 바이트 동일(엔진 대비), round-trip
   dequant 불변량, fixture 체인 PASS (skipif 엔진 바이너리), no-full-load gate (float peak =
   단일 expert slice).
6. DOC_SYNC: ROADMAP Phase 3, spec_draft (safetensors→GGUF 계약), RELEASE_NOTES v0.3.0 후보 갱신,
   본 Goal Result.
