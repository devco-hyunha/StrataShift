### FAIL → 닫음 (같은 Goal, AI 디버깅 루프)

첫 전체 실행 verify FAIL: expert 48 checks 전부 MISMATCH (max|d| ≈ 6.7e3).
- 정찰: pack expert 0 blob을 `rebuild_role`로 복원 → GGUF expert 0과 불일치, plane 바이트가
  GGUF에서 +16 어긋난 위치에서 발견. build 산출물은 우리 GGUF에서 재계산과 일치 → 원인은 GGUF 쪽.
- **원인 (근거 고정)**: 엔진 writer는 모든 tensor 뒤를 alignment pad (`gguf_writer.py:177-179`) →
  마지막 tensor(PLE 720 B) 뒤 trailing 16 B. 엔진 verify는 `data_section_offset =
  filelen − max(offset+expected_bytes)` (`canonical_xcheck.py:619-625`)로 data_start를 역산하므로
  trailing padding이 전 tensor를 +16 어긋나게 읽는다. p3-01 fixture는 마지막 tensor가 64 배수라
  trailing 0 (flush) — 엔진 convention은 **data section EOF flush**.
- **패치**: `cmd_emit_gguf` write 후 `data_start + max(offset+expected_bytes)`로 truncate.
- **재검증**: truncate 후 size 708,315,728, verify 0 bad, dense/PLE bit-exact, golden byte-identical.
  `docs/rea/struct_layouts.md §1` VERIFIED (p3-02) + `docs/polystrata_spec_draft.md` 4행 고정.
