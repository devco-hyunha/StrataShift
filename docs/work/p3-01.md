# Goal p3-01: 엔진 로드 스모크 — GGUF 인젝트 + 엔진 verifier/CLI self-check + 피드백 루프 1건

- Phase: 3 (PolyStrata 연동·피드백)
- Branch: `feat/p3-01-engine-load-smoke`
- Status: **in_progress (2026-10-15)**

## 한 줄 목표

변환 산출물(experts.bin + engine-format manifest.json + index.txt)을 핀된 PolyStrata 엔진의 CPU 검증 경로
(`strata-gguf --check`, `strata-dequant`, `tools/strata_pack.py build/verify`, `tools/pack_index.py`)에 주입하여
bit-exact 로드 self-check PASS를 얻고, 실패→REA 재대조→패치 기록 1건을 같은 Goal에서 닫는다.

## 현실 제약 (설계 게이트에 명시)

- 이 WSL 컨테이너에 GPU 없음 (`nvidia-smi` 없음, `/dev/nvidia*` 없음).
  CUDA 링크가 필요한 `strata-load`/`WeightTable::load`(cudaHostAlloc)는 **실행 불가**.
  → ACCEPTANCE Phase 3의 최소 게이트 "로더 self-check 통과"로 닫는다:
  엔진의 규격-of-record Python 도구(`strata_pack.py verify` = THE ONE RULE: decode(pack)==dequant_ggml bit-for-bit)
  + 엔진 CPU 바이너리(strata-gguf, strata-dequant, strata-plan)가 우리 산출물을 acceptance.
- GPU 있는 머신에서의 `WeightTable::load` 실로드(STRP 프로필 포함)는 백로그(§Out).

## In / Out

### In

1. **GGUF 인젝트** (`src/stratashift/ingest/gguf.py` — MODULE_DESIGN §1 `ingest/gguf.py` 후속 슬롯):
   GGUF v3 헤더만 스트리밍 파싱 (magic/version=3/n_tensors/KV/tensor dir/data_start=ceil(pos,align)).
   근거: `docs/rea/struct_layouts.md` §1 (SOURCE + DECOMPILED strata-gguf main: magic 0x46554747, v3 게이트, align 기본 32).
2. **GGUF convert 경로** (CLI `convert`가 `.gguf` magic 감지):
   - expert tensor `blk.{L}.ffn_{gate,up,down}_exps.weight` (Q2_0 type 42) → expert당 (gate,up,down)
     contiguous run 460,800 B씩 mmap 슬라이스 → blob 1,382,400 B relayout
     (`docs/rea/struct_layouts.md` §3 오프셋 표, `pack_layer.py:44-64` 근거) → experts.bin append.
   - dense/embd tensor → ALIGN=64 평면 정렬로 dense.bin/embd.bin 스트리밍 사본 (Q2_0는 VERBATIM 평면).
   - 산출물: `experts.bin`, `dense.bin`, `embd.bin`, `manifest.json` (엔진 strata-pack format v1),
     `index.txt` (dense/embd 행만 — 엔진 index는 `man["tensors"]`만 담음; expert는 blob stride 로드).
3. **엔진 형식 manifest writer** (`src/stratashift/meta/engine_manifest.py`):
   strata_pack.py build가 쓰는 필드 (`format/format_version/source/n_layers/align=64/codebooks/tensors/
   experts/n_experts_per_layer/files`)와 동일 형식. tensor entry 평면 필드: codes/scales/offsets
   {offset,bytes}, scales_fp16, source_type, form, code_bias, group_elems, block_elems, block_bytes,
   shape, elements, source_offset, file.
4. **엔진 형식 index writer** (`polystrata/index.py` 확장): pack_index.py 산출과 행 단위 byte-identical
   (3 헤더 라인 + 19필드 행; engine-form `dst_bytes = src_bytes + widen`, act_kind=VDT, codebook=IQ4NL flag).
5. **`stratashift verify` CLI** (Phase 2 CLI가 verify를 Phase 3로 명시):
   로컬 self-check — index 19필드/평면 합/`pool` 재계산, experts.bin 크기 = layers×NE×BLOB,
   Q2_0 구조 불변량(-d,0,d,2d) 샘플, 산출물 sha256 재계산 → manifest의 hash와 대조, 회귀 해시 재현.
6. **스모크 하네스** (`scripts/p3_engine_smoke.py` — 엔진 도구 read-only import, 엔진 소스 수정 없음):
   a. fixture GGUF 1레이어(H=2560,FF=640,NE=512)를 엔진 `tools/gguf_writer.py`의 `_Tensor`로 직접 구성
      (Q2_0 raw block bytes; gguf-py type42 불가 이유 = REA P0.S6 발견).
   b. `strata-gguf fixture --check` PASS, `strata-dequant fixture` PASS(0 violations) + CHECKSUM을
      Python `q2_0_unpack` 동일 바이트로 재계산해 일치 (2구현 교차).
   c. 엔진 `strata_pack.py build --gguf fixture --out golden --layers 1 --skip-hash` → golden pack,
      엔진 `verify` PASS.
   d. 우리 CLI `convert fixture --out ours` → experts.bin golden과 **byte-identical**, dense.bin/embd.bin
      byte-identical, manifest 평면 일치, index.txt 행 golden(pack_index.py 산출)과 byte-identical.
   e. 엔진 `strata_pack.py verify --gguf fixture --out ours` → **PASS** (엔진 verifier가 우리 산출물 acceptance).
   f. 회귀: 동일 입력·프리셋 → convert 2회 → sha256 동일.
7. **피드백 루프 1건 (ACCEPTANCE 산출물)**: 의도적 고의 오패킹(예: scale 평면 폭 2↔4 혼선) → 엔진 verify
   FAIL 로그 수집 → `docs/rea/` 재대조 → 우리 코드/문서 패치 → 재검증. **패치 기록 1건**을 Goal Result에 남긴다.
8. **테스트**: `tests/test_gguf_ingest.py` (소형 지오메트리 fixture: 파싱 + blob relayout + engine manifest
   평면 산수), `tests/test_engine_smoke.py` (skipif: 엔진 build/fixture/venv numpy 없으면 skip; 하네스 chain
   PASS + convert RSS flat gate), `test_no_full_load` 정적 게이트에 GGUF 경로 포함(전체 tensor read 금지).
9. **DOC_SYNC**: ROADMAP Phase 3 p3-01, docs/rea/README, polystrata_spec_draft
   (GGUF 인젝트·index 행 계약 갱신), RELEASE_NOTES v0.3.0-runtime 후보, 본 Goal Result.
   (ACCEPTANCE.md는 RO 마운트·인간 서명 문서 — 에이전트가 체크박스를 채우지 않는다.
   근거는 Goal Result와 위 DOC_SYNC 문서에만 남긴다.)

## 설계 요약

```text
[fixture GGUF (engine gguf_writer._Tensor, Q2_0 raw blocks)]
   → strata-gguf --check / strata-dequant          [엔진 CPU 바이너리 self-check]
   → strata_pack.py build → golden pack             [엔진 규격-of-record]
   → stratashift convert (GGUF ingest, expert당 460,800B mmap 슬라이스 → blob relayout)
   → byte-diff ours vs golden (experts.bin, dense.bin, embd.bin, index.txt)
   → strata_pack.py verify --out ours               [엔진 verifier acceptance = 로더 self-check]
   → 회귀 해시 2회 일치
   → (고의 오패킹 → verify FAIL → REA 재대조 → 패치 → 재검증)  [피드백 루프 1건]
```
