## 근거 계약 (pin c566ff4, tools/canonical_xcheck.py)

- MAPPINGS:565 `Q3_K`: form **S4**, code_bits=4, code_bias=−4, has_offset **False**,
  block 256 elems / 110 B, group_elems=16. gguf type id 11 (gguf_reader.py:22).
- 블록 레이아웃 (to_s4_q3_k, canonical_xcheck.py:209-247): hmask[32] + qs[64] + sb[12] + d fp16(2).
- 스케일 (unpack_q3_k_scales, :170-189): 12 B → 16 6-bit sc; group j(0..3)=lo(s[j])|2bit(s[8+j])<<4,
  4+j=lo(s[4+j])|2bit(s[8+j]>>2)<<4, 8+j=hi(s[j])|2bit(s[8+j]>>4)<<4, 12+j=hi(s[4+j])|2bit(s[8+j]>>6)<<4.
  dl_g = d·(sc6_g − 32) (integer bias 후 단 한 번의 f32 곱).
- 코드 (to_s4_q3_k docstring L1305 전사): group g = 8·half + 2·j + sub;
  요소 순서 e = 128·half + 32·j + 16·sub + l;
  c2 = (qs[half·32 + sub·16 + l] >> 2j) & 3; m = (hmask[sub·16 + l] >> (4·half + j)) & 1;
  code = c2 + 4·m (0..7). **hmask는 두 half가 같은 32 B를 재읽고 bit만 4·half+j로 이동** —
 qm은 half 간 리셋되지 않는다.
- dequant: v = (code − 4)·dl_g (from_s4_q3_k, :249-252).

## Producer 규칙 (HYPOTHESIS — 엔진에 양자화기 없음; 왕복 게이트로 검증)

- d = fp16(amax/63) (Q4_K/Q5_K/Q6_K와 동일 d 선택)
- sc6_g = clip(rint(gmax_g/d) + 32, 0, 63) (6-bit, bias −32 → signed −32..31)
- dl_g = d·(sc6_g − 32); code = clip(rint(w/dl_g) + 4, 0, 7); dl_g == 0 → code = 4
- 왕복 게이트(AC1): from_s4_q3_k(codes, scales) vs 원값, bound |w − v| ≤ |dl_g|/2
  (codebook −4..3 완전 커버 시).

## Packing (planes)

- codes plane: canonical codes(0..7)를 pack_codes(bits=4, per=2) LSB-first 순서대로
  (byte k = code[2k] | code[2k+1]<<4) — tools/strata_pack.py:60-76.
- scales plane: d·(sc6−32) f32 plane (choose_scale_dtype가 fp16 정확이면 fp16 선택).
- offsets plane 없음 (has_offset False).
- pack gate: elements % 256 == 0 (codes 128 B/block, scales 64 B/block f32).
