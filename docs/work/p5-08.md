## 한 줄 목표

우리 변환기의 dense 양자화 게이트를 엔진 load gate 계약(`shape[0] % be == 0`)에 정합시켜,
Gemma4 산출물이 `strata-poly` CUDA RUN을 통과하게 하고, RUN 실측 로그로 p5-07 AC5를 닫는다.

## root cause 실측 (p5-07 AC5, 2026-10-19 — 전수 sweep 정본)

- 엔진 `tensor_payload_bytes`(`include/strata/artifact/gguf_reader.hpp:505`, pin c566ff4):
  `shape[0] % be != 0`이면 payload = 0 → `runtime.hpp:168-172` "does not fit its file" throw.
- `block_geometry` 실측(same header, switch): Q4_K = case 12 (`be=256, bb=144`),
  Q8_0 = case 8 (`be=32, bb=34`), Q4_0 = case 2 (`be=32, bb=18`), F32 = case 0 (`be=1`).
- our GGUF 전수 sweep 실측(687 tensors):
  - `Q4_K ne0%256 FAIL = 30` — 30 layers 전부의 `ffn_down.weight [2112, 2816]` (잔여 64)
  - 30개 전부 `ne0%32 == 0` → `be=32` 양자화(Q4_0/Q8_0)로 대체하면 통과
  - Q2_0 expert 90개·F32 361개는 `ne0%be == 0` 통과 — fix 스코프는 `ffn_down` dense 30개 한정
- our gate(`cli/main.py::_dense_gate`)는 `n_el`(총 element)만 검사 — 엔진 load gate(ne0 검사)와 불일치.

## 설계 (fix 규칙)

1. gate 시그니처 확장: `_dense_gate(n_el, dense_type, ne0)` — `ne0`는 **engine shape
   (transpose 후)의 첫 dim**. HF [out,in]는 GGUF (in,out)로 transpose되므로 gate는
   engine shape의 shape[0]를 본다.
2. fallback 사다리 (엔진 `block_geometry` 실측 근거, 매직 넘버 금지):
   - 요청 dense_type의 `ne0 % be(dense_type) == 0`이면 그대로.
   - 아니면 `be=32` 양자화(`Q8_0` dense 기본, `Q4_0` 선택)의 `ne0 % 32 == 0`과
     pack contiguity(`n_el % 64 == 0`)를 만족하면 그 양자화로 emit.
   - 둘 다 실패하면 F32 pass-through(엔진 `be=1` 항상 통과).
3. pack contiguity gate(기존 `n_el % MIN_PACK_ELEMENTS`, strata_pack verify 게이트)는
   **유지** — 엔진 load gate(ne0)는 **추가**다. 둘 다 만족하는 type만 emit한다.
4. emit 경로 공통: `emit_dense`/`emit_dense_stream`가 같은 gate를 호출해야 한다
   (p4-03 byte-identical 계약 유지).
