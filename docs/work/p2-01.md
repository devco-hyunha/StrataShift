## 한 줄 목표

Expert blob 단위 제너레이터 루프(`mmap → pack → write → release`)로 Q2_0 tensor를
`experts.bin` + `index.txt`(19열) + 변환 매니페스트로 변환하고, CLI `convert`/`inspect`와
RSS 평탄성 게이트를 붙인다.

## In / Out

### In

1. `src/stratashift/quant/pack.py` — Q2_0 contract 구현 (docs/rea/bitpack_rules §1/§6 근거):
   - `q2_0_unpack(block18) -> list[float]` (스칼라 contract, DECOMPILED F5와 동일 식)
   - `q2_0_split(tensor_bytes) -> (codes_plane, scales_plane)` — pure relayout
     (codes = 각 block의 [2:18], scales = 각 block의 [0:2] fp16)
   - 구조 불변식 `{-d,0,d,2d}` 검증
2. `src/stratashift/stream/mmap_reader.py` — `iter_tensor_slices(path, refs)` 제너레이터:
   mmap 유지, slice 1개씩 yield, peak = 단일 slice.
3. `src/stratashift/meta/manifest.py` — `experts.bin` 순차 append writer + `index.txt` writer
   (19열, 헤더 `# align N pool M tensors K`) + 변환 매니페스트 JSON (출력 blob 크기·해시).
4. `src/stratashift/monitor/rss.py` — `/proc/self/status` VmRSS 샘플러.
5. `src/stratashift/cli/main.py` — `inspect <model> [--json]`, `convert <model> --out <dir>
   [--max-rss-gb N]` (Q2_0 tensor만 pack; 없으면 0-tensor 매니페스트).
6. tests:
   - `test_pack_matches_rea.py` — 합성 Q2_0 block 18B unpack/불변식/split 왕복
   - `test_stream_roundtrip.py` — 합성 Q2_0 tensor 여러 개 → experts.bin + index.txt 왕복
     (pack→unpack == 원본), index 19열·헤더 재파싱
   - `test_rss_flat.py` — 다중 blob 변환 중 VmRSS 샘플: 단조 증가 없음 + `--max-rss-gb` 안전 중단
7. DOC_SYNC: ROADMAP Phase2 체크, README, 본 Result.

### Out

### 설계

```text
convert(model, out):
  meta = parse_header(model)
  refs = build_expert_map(meta)            # fused/per-tensor
  for ref in refs (layer,expert,role 순):   # 제너레이터, 1개씩
      blob = next(iter_tensor_slices(...))  # mmap 단일 slice
      codes, scales = q2_0_split(blob)      # pure relayout (Q2_0 tensor만)
      append experts.bin; record index row (19 fields)
      release blob
  write index.txt + manifest.json (RSS peak 기록)
```

- 근거: Q2_0 contract = `bitpack_rules.md §1/§6` (SOURCE+DECOMPILED), index 19열 = `struct_layouts §4`,
  blob stride = `paging_model §2`. pack은 codes/scales를 **그대로 복사** (bit-exact relayout,
  `pack_layer.py:88-93` SOURCE).
- C1/C2: 전체 load 없음. `--max-rss-gb` 초과 시 안전 중단.
