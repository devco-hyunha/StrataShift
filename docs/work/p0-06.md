   REA는 인터페이스, Ghidra는 provider 엔진 (p0-05 규칙).
3. **소스 정찰 (B)** — 핀 zip 소스 트리 `.local/polystrata/PolyStrata-main/src/kernels/cpu/`:
   `q2_bitplane_parity.cpp`(opt-in STRATA_Q2_BITPLANE=1, AVX2/AVX1 전용 — "the AVX-512
   kernel does not read the image"), `expert_layout.cpp`(ActQ `qp/psum/pscale` plane),
   `expert.cpp`(multishift ARGUMENT ORDER 실측, probe_multishift.cpp 근거),
   `iq_avx512.cpp`(IQ 포맷 전용 — Q2_0 미포함).
4. **초기 정찰 결과 (2026-10-17, 소스 실측)**: `qp/psum/pscale`는 **ActQ = 활성화 양자화
   plane**(런타임 per-token, pack 바이트 아님) — `expert_layout.cpp:195-215`.
   HYPOTHESIS의 전제(가중치 bitplane가 pack에 별도 순서로 존재)는 성립하지 않으며,
   pack 바이트 contract는 스칼라 contract(struct_layouts §3 plane 분리)로 고정.
   parity 계약: integer part exact, float summation order만 차이 (few ulps).
5. **StrataShift 영향** — 변환기는 스칼라 contract만 구현 (bitpack_rules §5-5). B 해소는
   코드 변경 없음; pack byte contract 유지 확인만.
