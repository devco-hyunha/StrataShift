## 한 줄 목표

지원 Python을 3.11 이상으로 올리고, 텍스트 파일 읽기·쓰기에 모두 `encoding="utf-8"`을 붙이고,
엔진 연동 테스트에 필요한 패키지를 선택 의존성 `test`로 정리한다. 런타임 의존성은 `numpy` 하나 그대로.

## Review notes

- 서브 에이전트(소넷): 인코딩 일괄 수정 45곳(파일 26개: src 3, scripts 15, tests 8)과 가드 테스트
  `tests/test_text_encoding.py`를 맡겼다. 고치기 전 가드는 45곳을 잡아 실패했고, 고친 뒤 통과한다. 결과는 직접 검토했다.
- `test_packaging::test_install_gate`는 그동안 `tomllib` 때문에 한 번도 돌지 않았다. 3.11에서 처음 돌려 보니
  Windows 스크립트 위치가 달랐다. `pip --target`은 Windows에서도 `bin/`에 넣고 `.exe`만 붙인다(pip 24.0 실측).
- `test_rss::test_child_rss_sees_allocation`(p6-10)이 3.11 가상환경에서 실패했다. Windows 가상환경의 `python.exe`는
  진짜 인터프리터를 자식으로 띄우는 실행기라서 `Popen.pid`가 할당한 프로세스가 아니었다(측정값 약 9.7 MB).
  자식이 `os.getpid()`를 알려 주도록 테스트를 고쳤다. `rss.py`는 맞게 동작한다.
- 기준 해시는 3.10에서 기록했다. 3.11에서도 31/31 일치한다(출력 바이트 같음). 힙 최댓값 변화율은
  3.11 17.04% / 3.10 0.78%다. 3.11 차이는 인터프리터 버전의 할당 차이로 본다(같은 코드를 3.10에서 돌리면 0.78%).
