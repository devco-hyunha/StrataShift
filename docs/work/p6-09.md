## 설계

### 경로 정하는 순서

| 경로 | ① 옵션 | ② 환경 변수 | ③ 기본값 |
| --- | --- | --- | --- |
| 엔진 소스 | `--engine-src` | `STRATASHIFT_ENGINE_SRC` | `<저장소>/.local/polystrata/PolyStrata-main` |
| 엔진 도구 | (`--engine-src`/`tools`) | `STRATASHIFT_ENGINE_TOOLS` (기존 이름) | `<엔진 소스>/tools` |
| 엔진 빌드 | — | `STRATASHIFT_ENGINE_BUILD` | `<저장소>/.local/polystrata/build` |
| gguf-py | — | `STRATASHIFT_GGUF_PY` | `<엔진 빌드>/_deps/strata_llamacpp-src/gguf-py` |
| 임시 폴더 | — | `STRATASHIFT_SCRATCH` | `tempfile.gettempdir()/stratashift` |

- 옵션이 환경 변수보다 먼저다. `--engine-src`를 주면 도구 경로도 `<옵션>/tools`가 된다.
- `<저장소>`는 `engine_paths.py` 위치에서 세 단계 위(`src/stratashift/polystrata/` → 저장소 뿌리).
  `pip install -e .`(편집 설치)에서 맞는다. 일반 설치에서는 그 위치에 `.local`이 없으므로
  환경 변수나 옵션을 써야 하고, 없으면 ④처럼 분명히 알린다.
- ④ 찾지 못하면: emit은 지금처럼 종료 코드 2로 거절하되, 메시지에 **찾아본 경로**와
  **바꿀 수 있는 옵션·환경 변수 이름**을 적는다.
- 실행 파일: `engine_binary(name)`이 Windows에서는 `name.exe`를 붙이고,
  `<빌드>/name(.exe)`와 `<빌드>/Release/name(.exe)`(MSVC 다중 구성 생성기) 순서로 찾는다.
  없으면 첫 후보 경로를 돌려준다(건너뜀 메시지에 쓰도록).
- 기존 WSL 환경은 환경 변수 3개로 그대로 동작한다:
  `STRATASHIFT_ENGINE_SRC=/opt/data/polystrata-src`,
  `STRATASHIFT_ENGINE_BUILD=/opt/data/polystrata-build`,
  `STRATASHIFT_SCRATCH=/opt/data/cache/scratch`.

### 공개 함수 (`polystrata/engine_paths.py`, I/O 없음 — 경로 계산과 존재 확인만)

- `EnginePaths` (frozen dataclass): `src`, `tools`, `build`, `gguf_py`, `scratch`
- `resolve_engine_paths(engine_src: str | None = None) -> EnginePaths`
- `engine_binary(paths, name) -> Path`
- `exe_name(name) -> str`
- `scratch_dir(paths=None) -> Path` — 만들어서 돌려준다
- `describe_missing(path, env_names) -> str` — 건너뜀·오류 메시지 한 줄

### `engine_tools.py` 바꾸는 점

- 지금: 모듈을 import하는 순간 `/opt/data/...`를 `sys.path`에 넣고 `gguf_writer`를 import.
- 바꾼 뒤: `load(engine_src=None) -> bool`이 경로를 정하고 import한다. 처음 한 번만 하고,
  `available()`도 처음 부를 때 `load()`를 부른다. 그래서 `--engine-src`가 import보다 먼저
  적용된다. 다른 모듈은 이미 `engine_tools.GGUFWriter`처럼 모듈 속성으로만 쓰므로 그대로 둔다.
- `TYPE_IDS` 확장 값과 근거 주석(핀 `c566ff4`)은 그대로 옮긴다.

### 테스트·스크립트

- `tests/conftest.py`(새 파일): 모듈 수준에서 `resolve_engine_paths()`로 도구·`ref` 폴더를
  `sys.path`에 넣고, `engine_paths` fixture를 준다. 테스트 파일마다 있던 `sys.path.insert`는 지운다.
- 건너뜀 조건(`skipif`)에 쓰는 상수는 `resolve_engine_paths()`로 구한다(수집 시점에 필요해서).
- 스크립트의 출력 폴더 `/opt/data/cache/scratch/...` → `scratch_dir()/...`.
