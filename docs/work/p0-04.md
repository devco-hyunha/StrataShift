## 근거 (매직 넘버 금지)

- 레이아웃: `struct_layouts.md §5` — magic "STRP"(4B), `version,n_layers,n_expert,slots,n_ranked`
  (5×u32 LE @4), `n_ranked × (u16 layer, u16 expert)` @24, `int32[nl×ne]` rank 배열(−1 non-resident)
  @24+4·n_ranked. 파일 크기 공식 24 + 4·n_ranked + 4·nl·ne.
- 게이트 semantics: `DECOMPILED: expert_cache.o read_expert_profile @ 001048f0` — magic 0x50525453,
  version!=1 거부, nl/ne 모델 대조, n_ranked > want 거부. 우리 writer/parse는 같은 거부 조건을 mirror.
- 실물 표본: `/opt/data/polystrata-src/data/expert-profile.bin` (p0-02에서 필드·첫 pair·크기 VERIFIED).
