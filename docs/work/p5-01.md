## 한 줄 목표

`pyproject.toml`에 console script entry point(`stratashift`)와 현행 마일스톤 버전(0.4.0)을
추가하고, 실 설치 게이트 테스트(pip install → 설치된 CLI 실행)를 통과시킨다.

## 근거 (ROADMAP Phase 5 작업 1, planned scope)

- ROADMAP p5-01: "`pyproject.toml` 버전·console script(`stratashift = stratashift.cli.main:main`)·
  설치 게이트 테스트. 런타임 의존 추가 금지(C1: safetensors/torch 금지 유지)."
- 현행 pyproject: version 0.0.1, `[project.scripts]` 없음, 런타임 의존 없음 (주석으로 C1 기록).
- `main(argv) -> int` (cli/main.py:1195) — exit code 반환. console script는 반환값을 exit code로
  쓰지 않으므로 `cli_entry()` 래퍼(`raise SystemExit(main())`)로 exit code 규격(0/1/2)을 전파한다.
  (p5-02의 exit code polish 전제.)
