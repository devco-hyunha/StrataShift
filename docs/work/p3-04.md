## 근거

- Q4_K contract: `canonical_xcheck.py` MAPPINGS:567 `Mapping(to_s4_q4_k, from_s4_q4_k, 144, 256, 32, "S4", None, 0, True)`
  — block 144 B, 256 elems, group 32, **has_offset True** (3 planes), code_bias 0.
- `to_s4_q4_k` (:128-160, pin c566ff4): d=fp16(x.d), dmin=fp16(x.dmin), 12 packed scale bytes →
  `get_scale_min_k4`(:111, ggml-quants.c L880 전사)로 8 groups의 (sc, m); scales = d*sc,
  offsets = -(dmin*m); codes: low nibbles = group is+0, high nibbles = group is+1 (저니블 앞/고니블 뒤,
  4 32-byte steps → 8 groups of 32).
- `from_s4_q4_k`: `v = code*scales + offsets` (group broadcast) — dequant 왕복 계약의 복원식.
- 엔진 pack gate (p3-03 VERIFIED 확장): `pack_index.py:144-152` plane 연속 + `strata_pack.py:43`
  ALIGN=64. Q4_K codes plane = 256 codes × 4 bits = 128 B/block (128n, 64 배수 항상). scales plane
  = 8×4 B = 32 B/block. offsets plane = 32 B/block. offsets 시작 = 128n+32n = 160n; 연속 조건
  160n % 64 == 0 → **n even → elements % 512 == 0**.
- 엔진에 quantizer 없음(gguf_writer Q2_0 전용) — producer 규칙 = llama.cpp `quantize_row_q4_K_ref`
  계열 (amax→d, group sc/m) = **HYPOTHESIS**. acceptance 게이트는 엔진 dequant 왕복 + strata_pack verify.
- 우리 S4 평면 기계는 Q4_0/IQ4_NL로 검증됨(p3-03, p3-01). Q4_K는 같은 S4 + offsets plane 추가.
