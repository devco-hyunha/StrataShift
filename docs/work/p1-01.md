## 한 줄 목표

모델 전체를 RAM에 올리지 않고 `.safetensors` 헤더(mmap)에서 텐서 이름·dtype·shape·data_offsets를
추출하고, MoE FFN Expert 후보 맵(JSON)을 출력하는 `ingest`/`meta` 모듈 + PoC 스크립트 +
`test_no_full_load` 게이트를 만든다.

## In / Out

### In

1. `src/stratashift/ingest/safetensors_header.py` — `parse_header(path) -> ModelMeta`
   - 8B u64 헤더 길이 → JSON 헤더만 읽음. 데이터 본체 복사 금지 (mmap/헤더 바이트만).
   - `TensorMeta(name, dtype, shape, data_offsets)`, `header_size`, `data_start`(8B 정렬).
2. `src/stratashift/meta/expert_map.py` — `build_expert_map(meta) -> list[ExpertRef]`
   - Expert 이름 규칙 초안: `layers.<L>.(mlp.)experts.<E>.(gate|up|down)_proj` (+ `w1/w2/w3`,
     `moe.layers.<E>` 변형). layer/expert id, role, tensor명, offsets.
3. `scripts/poc_parse_header.py` — CLI 데모: 헤더 파싱 + Expert 맵 JSON 출력 + 단일 레이어
   슬라이스 1개 mmap 읽기 데모 (변환 전, 읽기만).
4. `tests/test_header_parse.py` — fixture 합성 헤더로 shape/offset 정확성.
5. `tests/test_no_full_load.py` — (a) 소스에 금지 API(`safetensors.torch.load_file`,
   `torch.load`, `state_dict` 전체) 없음 정적 검사, (b) 실모델 헤더 파싱 시 RSS 피크가
   헤더+1슬라이스 수준 (tracemalloc/RuMaxSan 피크 측정).
6. `pyproject.toml` (src layout, 의존성 없음 — 헤더 파싱은 stdlib json/struct/mmap).
7. 테스트 모델: `.local/models/mixtral-tiny.safetensors` (HF `hf-internal-testing/tiny-random-MixtralForCausalLM`, gitignore) — SHA256 기록.
8. DOC_SYNC: ROADMAP Phase1 체크, MODULE_DESIGN(변경 없음 — 설계대로), README/INDEX 링크, 본 Result.

### Out

- 변환·양자화·패킹 (Phase 2), polystrata 상수 (p0-03), CLI convert (Phase 2), GGUF 파서 (후속)

## 설계 요약

```text
[open] → read 8B u64 → read header_len bytes JSON → tensors{dtype,shape,offsets}
       → data_start = 8-aligned(header_len)  (safetensors spec)
[ExpertRef] = regex 규칙 → (layer, expert, role, name, offsets)
[PoC] mmap → 단일 expert 슬라이스 1개 bytes → 해시 출력 (전체 복사 없음)
```

- safetensors 포맷 근거: https://huggingface.co/docs/safetensors (헤더 JSON + 8B 정렬)
- Expert 규칙은 **후보** — Phase 3 로드 검증 전 `HYPOTHESIS:` 아님: 규칙은 이름 패턴 사실,
  "FFN Expert" 확정도 패턴 기반 (ACCEPTANCE Phase1 "후보 텐서를 나열").
- CONSTRAINTS C1/C2: `load_file`/`torch.load`/전체 state_dict 경로 없음.
