## 실측된 갭 (2026-10-18, p5-03 quickstart 준비 중 발견)

1. **verify disconnect**: `convert --out`는 p2 stream pack manifest
   (keys: packed_rows/pool_bytes/experts_bin_sha256…)를 `manifest.json`에 쓰고,
   HF fused path도 동일. `cmd_verify`(main.py:927)는 engine-form manifest
   (`man["tensors"]`, `man["experts"]`, `man["align"]`, `n_layers`, `n_experts_per_layer`)를

   harness가 build_manifest로 engine-form을 직접 써서 verify PASS).
   최종 연결 = emit path가 engine-form manifest를 `manifest.json`에 기록하고
   verify가 그 계약(19-field rows, plane sums, pool recompute, experts.bin size, hashes)을
   검사.
2. **dispatch auto-detection 문서-구현 갭**: p4-01 RELEASE_NOTES 클레임
   "auto-detected, flag forces the HF path" — 실 구현은 `args.hf_emit` 플래그로만 HF 경로
   (main.py:1241). HF naming + BF16 dense가 플래그 없이 `cmd_emit_gguf`(F32-dense 전용)에
   걸려 `ValueError: lm_head.weight: only F32 dense tensors supported` 실측.
   dispatch가 `is_hf_naming(meta)`를 자동 판정해 HF emit으로 라우팅하고, 플래그는 강제 유지.
3. **uncaught exceptions**: `cmd_inspect`의 FileNotFound, emit의 ValueError 등 —
   exit code 1의 사용자 메시지 없이가 traceback 노출. main() 전역 catch로
   stderr 한 줄 + exit code 규격(0=ok, 1=runtime, 2=usage, 3=max-rss) 확정.
4. `verify` exit code: PASS 0 / FAIL 1 실측.

## Root cause·fix·재검증 (AC4 전수 실행, 2026-10-18)

- **전수 suite 실측**: 1 failed / 99 passed (6264.33s) — `test_no_full_load::test_header_parse_peak_memory`
  peak 1,123,499 B > budget 1,008,864 B. 단독 실행은 GREEN (peak 133,770 B, margin 875,094 B)
  → suite 순서 간섭 실측. 선행 그룹(cli+engine_smoke+header+hf_map+no_full) 재현 = deterministic
  재현 (1 failed / 24 passed, 754.83s, `/opt/data/cache/scratch/p5-02-repro.log`).
- **가설→실측**: 예외 경로가 `tracemalloc.stop()`를 bypass. `cmd_emit_gguf`가
  `tracemalloc.start()` 후 BF16 `ValueError`를 raise → trailing `stop()` 미실행 → tracemalloc가
  세션 내내 active. `test_no_full_load`의 `tracemalloc.start()`는 no-op(이미 active) →
  peak = 세션 누적 peak 측정. 실측: `_run()` 후 `tracemalloc.is_tracing() == True` 확인.
- **fix (root cause, 발명 없는 최소 구조)**: `heap_gate()` contextmanager — start/stop를
  예외·return 3(RSS abort)·normal return 전 exit path에서 짝 강제. 네 측정 함수
  (`cmd_convert_safetensors`·`cmd_convert_gguf`·`cmd_emit_gguf_hf`·`cmd_emit_gguf`)를
  wrapper+`_body`로 분리, body는 gate 안에서 실행.
- **regression gate**: `tests/test_cli_exit_codes.py` BF16 테스트에
  `assert not tracemalloc.is_tracing()` 실장 (exception 후 tracer non-active 강제).
- **재검증**: 선행 그룹 재현 GREEN (repro2) → 전수 suite 재실행 GREEN 확인 후 AC4 확정.
