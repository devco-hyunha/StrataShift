## 근거 계약 (pin c566ff4, tools/canonical_xcheck.py)

- MAPPINGS:571 `Q8_0`: form **S8**, code_bits=8, code_bias=−128, has_offset **False**,
  block 32 elems / 34 B, group_elems=32. GGUF type id **8** (engine gguf_reader.py GGML_TYPES;
  우리 ingest/gguf.py GGML_TYPES:24, BLOCK_GEOMETRY "Q8_0": (32, 34) — 이미 수용).
- 블록 레이아웃 (to_s8_q8_0, canonical_xcheck.py:58-77): d fp16(2) + qs[32] int8.
  코드 평면은 UNSIGNED: int8 code를 +128해 저장, dequant는 integer 안에서 −128을 되돌린다
  (Q2_0 −1, Q4_0 −8과 같은 정수 bias 메커니즘, docstring: "ONE code-plane contract").
- dequant (from_s8_q8_0, :80-84): v = (code − 128) · d, d = fp16→f32.
- 엔진 quantizer 존재 (Q4_0/K-quant와 다름): `tools/mtp_pack.py:100 q8_0` —
  d = amax/127 (f32), inv = 1/d (d==0 → 0), q = np.rint(x·inv).astype(int8),
  저장 d = fp16(d). `tools/mtp_rt.py:34`는 round-half-away-from-zero 변형 —
  **계약은 mtp_pack.py (np.rint = C rint, 반올림 ties-to-even)**.
- 경계 (contract domain): d = amax/127가 fp16에 표현되는 범위만 — amax ≤ 65504·127 = 8,319,008
  (mtp_pack.py:102의 d.astype(np.float16)가 overflow 시 inf → dequant 무의미.
  경계에서 테스트, 경계 밖은 계약 domain이 아님).

## Producer 규칙 (VERIFIED — 엔진 quantizer 바이트 동일 게이트)

- d = amax/127 (f32), q = clip(rint(w·(1/d)), −127, 127) (amax==0 → inv=0 → q=0),
  저장: fp16(d) + (q+128 as uint8). 게이트: `quantize_q8_0_stream` == `mtp_pack.q8_0`
  바이트 동일 (random trials + edges: all-zero block, tiny amax, large amax,
  fp16-boundary amax = 8,319,008).

## Packing (planes)

- codes plane: qs bytes verbatim (S8, pack_codes bits=8 → per=1, strata_pack.py:60-67의
  bits==8 identity 경로) = 32 B/block.
- scales plane: fp16 2 B/block — d는 fp16 by construction → scales_fp16 True
  (choose_scale_dtype, strata_pack.py:90-95).
- offsets plane 없음 (has_offset False).
- pack gate (VERIFIED 고정): codes plane 32n B, scales 시작 = align64(32n)
  (`strata_pack.py:43` ALIGN=64), 연속성 요구 `pack_index.py:144-152` (scales offset ==
  codes bytes) → 32n % 64 == 0 → n even → **elements % 64 == 0**
  (`Q8_0_MIN_PACK_ELEMENTS = 64`). **추가 요구 (p3-09 실측, pack_index.py:174-186)**:
  scales 산수 = ne1·n_groups (ne1 = GGUF shape[1]) → 1-D 텐서(ne1=0)는 derived scales 0
  → pack_index 거부 ("derived planes disagree") → 1-D 텐서도 F32 pass-through.
  미만/1-D는 엔진 self-build도 pack_index 거부 → emit은 F32 pass-through 유지
  (Q4_0/Q4_K/Q5_K/Q6_K/Q3_K 동일 정책).
