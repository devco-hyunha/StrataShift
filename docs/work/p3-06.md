## 근거

- Q6_K contract: 설치 핀 `canonical_xcheck.py` MAPPINGS:570 `Mapping(to_s8_q6_K, from_s8_q6_K, 210, 256, 16, "S8", None, -32, False)`
  — block 210 B, 256 elems, group **16**, form S8, code_bias −32, **has_offset False** (2 planes), code_bits(form)=8.
- `to_s8_q6_K` (:422-468, pin c566ff4): ql[128], qh[64], sc[16] **signed int8**, d=fp16.
  4 quads from ONE qh[l]: q1=(ql[l]&0xF)|((qh[l]>>0&3)<<4), q2=(ql[l+32]&0xF)|((qh[l]>>2&3)<<4),
  q3=(ql[l]>>4)|((qh[l]>>4&3)<<4), q4=(ql[l+32]>>4)|((qh[l]>>6&3)<<4), each −32.
  quads land at STRIDES of 32: q1→l+0, q2→l+32, q3→l+64, q4→l+96 → group = element/16 (plain consecutive
  16-element groups, 16 groups per block). `d*sc*q` associates LEFT: group scale = fl(d·float(sc)).
- `from_s8_q6_K`: v = (code−32)·(d·sc) — dequant 왕복 계약의 복원식. signed sc 보존.
- 엔진 pack gate (p3-05 기계 확장): codes plane = 256 codes × 1 B (S8, pack_codes per=1) = 256 B/block
  (64 배수 항상), scales = 16 groups × 4 B = 64 B/block. offsets 없음. codes 256n % 64 == 0,
  scales 시작 256n % 64 == 0 → **gate = elements % 256 == 0** (block multiple).
- 엔진에 quantizer 없음 — producer 규칙 = llama.cpp `quantize_row_q6_K_ref` 계열 = **HYPOTHESIS**:
  d = fp16(amax/63); sc_g = clip(rint(gmax_g/d), −63, 63) (signed, gmax는 signed max);
  code = clip(rint(w/(d·sc_g)) + 32, 0, 63); bound |w−v| ≤ d·|sc_g|/2.
- 우리 S8 평면 기계(q5_k_planes, engine_rows codes 산수 ceil(elems/(8//bits)))는 검증됨(p3-05).
  Q6_K는 offsets plane 없음 + signed int8 sc + group 16 추가.
