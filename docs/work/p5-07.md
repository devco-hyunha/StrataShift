## VRAM feasibility (가설 — 게이트 실측 전 확정 금지)

- 엔진 실측 residency: `h_expert` 0.6447 @ 4,105 slots, 5,413 MiB, steady free 6,414 MiB
  (`paging_model.md` §3) → 4 GiB VRAM은 그 실측 구성 그대로 **초과**.
- cache/ring는 byte budget 기반(`ring_bytes()`, `STRATA_RING_BYTES` env, `expert_cache.hpp`
  residency plan) → 4 GiB 안에서 사는 plan 구성 가능성은 **미검증**. CONSTRAINTS §61:
  CUDA에서도 모델 전체 VRAM 적재 금지 — 엔진은 스트리밍 design이므로 게이트에서 RSS/VRAM
  샘플로 검증한다 (`monitor/rss.py` + VRAM 샘플은 GPU 의존 백로그 해소와 동일 지점).
- Pinned host RAM: `PinnedArena` = layers × experts × blob (`load_main.cpp:47-60` DECOMPILED
  `0x151800`/`0x200` 일치). Gemma4 geometry(128 experts/layer) 기준 PC RAM 여유 필요 —
  AC5 직전 PC RAM 실측(사용자) 게이트.
