- `emit` 묶음은 `convert --emit-gguf`에 지금 연결한다.
- `engine-build` 묶음(CMake·MSVC·CUDA)은 단위 테스트와 이 PC 실측(`--dry-run` 계획)까지 하고,
  명령 연결은 3e의 엔진 빌드 단계에서 한다.

### 핀 엔진 소스 검증

- zip 파일 해시는 쓸 수 없다. 기록된 zip(`binary_pin.md` `3ecc0e4c…`)은 그때의 `main` zip이고,
  커밋 zip은 최상위 폴더 이름(`PolyStrata-<sha>`)이 달라 파일 해시가 반드시 다르다.
- 대신 **내용 해시**를 쓴다: zip 안 파일마다 (최상위 폴더를 뗀 경로, 내용 sha256)를 경로 순으로 이어 sha256.
  기록된 핀 zip과 지금 풀린 폴더 모두 `905d413e21aecce5f643eac307a818adea143cfa58a626788982087e35c605ae`
  (파일 3,261개, 2026-10-22 실측). 이 값을 코드에 박는다(핀 근거: `docs/rea/binary_pin.md`).
- 다르면 받은 파일을 지우고 멈춘다. 압축 풀기는 임시 폴더에 한 뒤 이름을 바꾼다. 경로가 폴더 밖을 가리키는 항목이 있으면 멈춘다.
- 출처는 GitHub만 자동으로 쓴다. HF Space 백업은 최신 소스라 핀 내용 해시와 맞을 보장이 없다.
  GitHub에 실패하면 HF Space 주소와 손으로 하는 방법을 안내하고 멈춘다(AGENTS: GitHub 실패 시 HF 백업 — 받은 것이 핀 해시와 맞을 때만 쓸 수 있다).

### 실행 흐름 (`install/ensure.py` `ensure_need(need, yes, dry_run)`)

1. 확인: 묶음의 항목마다 있는지 본다. 모두 있으면 아무것도 출력하지 않고 통과.
2. 계획 출력: 없는 항목의 이름·크기·시간·관리자 권한 여부.
3. `--dry-run`: "설치하지 않음"을 알리고 종료 코드 0 (`convert`는 변환하지 않고 끝난다).
4. 리눅스 등: 자동 설치하지 않는다. 설치 방법을 알리고 2.
5. 경로를 옵션·환경 변수로 직접 준 경우(`--engine-src`, `STRATASHIFT_ENGINE_SRC`/`_TOOLS`): 그 위치에는 설치하지 않는다(사용자 폴더를 덮어쓰지 않기). 알리고 2. 자동 설치는 저장소 안 기본 위치(`.local/`)에만 한다.
6. 묻기: `--yes`/`STRATASHIFT_YES=1`이면 묻지 않는다. 입력이 터미널이 아니면 "--yes를 주라"고 알리고 2. `[y/N]`, `y`가 아니면 2.
7. 설치: winget 항목은 winget이 없으면 "Microsoft Store의 앱 설치 관리자(App Installer)" 안내 후 2. 실행할 명령을 그대로 출력한 뒤 실행.
8. 다시 확인: 같은 확인 함수로 본다(winget 종료 코드는 믿지 않음, setup.py:4085-4092). 없으면 무엇이 실패했는지,
   손으로 하는 방법(`docs/USAGE.md` "자동 설치"), PATH가 아직 안 바뀌었을 수 있으니 새 창에서 다시 실행하라고 알리고 2.
