  → GPU 게이트는 **p5-07(사용자 PC WSL)**로 이관. 단, 본 sandbox 컨테이너는 GPU passthrough 없음
  (`/usr/lib/wsl/lib`·`/dev/nvidia*`·`/dev/dri` 부재 실측) + `/mnt/c` 미마운트(9p 화이트리스트
  파일만) → CUDA 빌드·RUN 실측은 사용자 PC WSL 디스트로에서만 수행 가능하다.
  VRAM 4 GB feasibility는 가설 금지: 엔진 실측 residency 5,413 MiB @ 4,105 slots
