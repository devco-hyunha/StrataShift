## 근거

- Q5_K contract: `canonical_xcheck.py` MAPPINGS:568 `Mapping(to_s8_q5_k, from_s8_q5_k, 176, 256, 32, "S8", None, -16, True)`
  — block 176 B, 256 elems, group 32, **has_offset True** (3 planes), code_bias −16, code_bits 5.
- `to_s8_q5_k` (:370-415, pin c566ff4): d=fp16(x.d), dmin=fp16(x.dmin), 12 packed scale bytes →
  `get_scale_min_k4`로 8 groups의 (sc, m); scales = d*sc, offsets = -(dmin*m); codes 5-bit:
  lo = (qs[j*32+l] & 0xF) + (qh[l] & u1 ? 16 : 0), hi = (qs[j*32+l] >> 4) + (qh[l] & u2 ? 16 : 0),
  u1 = 1<<(2j), u2 = 2<<(2j) — qh는 4 64-element steps에서 같은 32 bytes를 재읽고 u1/u2가
  1,4,16,64 / 2,8,32,128로 walk. group is+0 = low nibbles, is+1 = high nibbles (Q4_K와 동일 shape).
- `from_s8_q5_k`: `v = code*scales + offsets` (group broadcast) — dequant 왕복 계약의 복원식.
- 엔진 pack gate (p3-04 VERIFIED 확장): codes plane = 256 codes × 8 bits (S8) = 256 B/block
  (64 배수 항상). scales 32 B/block, offsets 32 B/block. offsets 시작 = 256n+32n = 288n;
  연속 조건 288n % 64 == 0 → **n even → elements % 512 == 0** (Q4_K와 동일 gate).
- 엔진에 quantizer 없음 — producer 규칙 = llama.cpp `quantize_row_q5_K_ref` 계열 = **HYPOTHESIS**.
  acceptance 게이트는 엔진 dequant 왕복 + strata_pack verify.
- 우리 S4/Q4_K 평면 기계는 검증됨(p3-03, p3-04). Q5_K는 같은 get_scale_min_k4 + 5-bit qh plane 추가.

## In

1. `quant/pack.py`: `quantize_q5_k_stream(values)` — float32 1-D (256의 배수) → 176 B 블록 스트림.
   규칙(HYPOTHESIS): d = fp16(amax/63); group sc = clip(round((gmax−gmin)/d),1,63),
   m = clip(round(−gmin/d),0,63) (groups 4..7 m<16); code = clip(round((w+d*m)/(d*sc)),0,31);
   qh[l] bit (2j) = code_low≥16, bit (2j+1) = code_high≥16; qs[l] = code_low&0xF | code_high&0xF<<4.
   `q5_k_unpack(block)` — `to_s8_q5_k` 전사 (get_scale_min_k4 + qh u1/u2 walk)로 왕복 검증.
2. `meta/engine_manifest.py`: `q5_k_planes(raw)` — GGUF Q5_K blocks → (codes 8-bit, f32 scales,
   f32 offsets) 3-plane. `to_s8_q5_k` + `pack_codes`와 동일 바이트.
   FORM_INFO["Q5_K"]: form S8, codebook None, code_bias −16, has_offset True, block 176, group 32, code_bits 5.
   `tensor_entry`에 Q5_K 분기 (S8 codes plane, scales/offsets choose_scale_dtype).
3. `cli/main.py`: `--dense-type`에 `Q5_K` 추가. dense F32 → Q5_K tensor 기록 (shape 유지).

4. 엔진 acceptance: Q5_K dense GGUF에 strata-gguf --check PASS + strata_pack build+verify PASS
